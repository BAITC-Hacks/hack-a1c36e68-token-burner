# Стабильность результатов на red8 → red9

Matcher использует LLM (gpt-5.5), поэтому повторные прогоны на одних и тех же документах дают
немного разные наборы выводов. Верификатор цитат детерминирован: ни один подтверждённый вывод
в этих прогонах не ссылался на несуществующий пункт или неточную цитату.

Ниже — 8 прогонов на gpt-5.5, проверенных по Validation set (`python -m tests.validation_set <result.json>`).
run6 и run7 выполнены до добавления в промпт Matcher правила «проверка по действию»; начиная с run8 промпт
Matcher финальный. Прогоны api_fresh_1 и api_fresh_2 — полные прогоны через API без кэша извлечения,
как у проверяющего; api_fresh_2 сохранён как `data/demo_result.json`.

Что ещё меняется от прогона к прогону: общее число выводов (40–52), число подтверждённых дублей (3–8),
число изменённых функций. Число конфликтов после введения уровней уверенности (run10, api_fresh_1,
api_fresh_2) — 2 во всех трёх прогонах; остальные кандидаты уходят в «пересечение ответственности».

Время и стоимость полного прогона без кэша через API: 200–220 с, $2.7–2.9 (извлечение gpt-5-mini
≈ $0.31, сопоставление gpt-5.5 ≈ $2.4–2.6). С кэшем извлечения: 110–130 с, $1.6–2.8.

Ограничение для README: выводы о дублях и о спорных потерях зависят от суждения модели и могут
отличаться между прогонами; поэтому каждый вывод помечен как требующий проверки сотрудником, а
программно гарантируется только то, что каждая цитата существует в указанном пункте.
